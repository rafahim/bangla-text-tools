# Bangla Text Tools
> Free offline Bengali text utilities — converter, spell checker, word counter.

[Live Demo](https://rafahim.com/bangla-text-tools/)

## 👨‍💻 Author — RA Fahim · rafahim.com · github.com/rafahim · @rafahimn · dev@rafahim.com

RA Fahim is a Web Developer & Creator based in Dhaka, Bangladesh, focused on full-stack web products and practical browser tools.

## ✨ Features

- Live character, word, sentence, paragraph, line and reading-time stats
- Bengali-focused whitespace, line-break and punctuation cleanup
- Line deduplication, Bengali-aware A-Z/Z-A sorting and reverse
- UPPER, lower, Title and Sentence case tools
- Bangla ০-৯ ↔ English 0-9 digit conversion
- Bijoy / ANSI → Unicode with pre-sign and post-sign reordering
- Unicode → Bijoy with legacy sign ordering
- 5,000 bundled Bengali word forms for offline spell checking
- Top-3 Levenshtein spelling suggestions
- Reverse, copy, download and clear
- Toast notifications
- Light/dark mode
- Mobile-first responsive UI
- No framework, npm, build step, API or external runtime dependency

## 🔐 Privacy

The app is client-side only. Text is processed inside the browser. No text is uploaded to RA Fahim, a third-party API, analytics service or cloud database.

## 🚀 Run

Open `index.html` directly in a modern browser. A local HTTP server also works.

## 📁 Files

`index.html` contains the semantic page, SEO metadata and JSON-LD.

`style.css` contains the responsive light/dark UI.

`script.js` contains editor operations, conversion, spelling and interactions.

`dictionary.js` contains the bundled offline Bengali word-form set.

`manifest.json` contains PWA metadata.

`robots.txt`, `sitemap.xml`, `humans.txt` and `.well-known/security.txt` provide crawler, sitemap, project and security metadata.

`favicon.svg` is the RAF green monogram icon.

`og-image.svg` is the 1200×630 social preview.
